# Changelog

All notable changes to B3GET are recorded here, in plain language, so this file alone is
enough to reconstruct what happened and why — for a paper, a grant report, or just future
reference.

Format: one entry per merged PR, newest first, under the version/period it belongs to.
Until a new versioned release is cut, entries go under `Unreleased`.

## Unreleased

- Added `CLAUDE.md`, this changelog, and a PR description template to establish a
  documentation-first workflow for future changes. No model behavior changed.

## Released versions

Prior versions (`v1.2.0`, `v1.3.0`, `v1.3.1`) predate this changelog and were tracked as
dated snapshot folders under `Version history/` instead. See each version's own `README.md`
/ `codemeta.json` for what changed between them.
