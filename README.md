# B3GET

B3GET simulates populations of virtual organisms evolving over generations, whose evolutionary
outcomes reflect the selection pressures of their environment. The model simulates several factors
considered important in biology, including life history trade-offs, investment in fighting ability
and aggression, sperm competition, infanticide, and competition over access to food and mates.
Downloaded materials include starting genotype and population files. Edit these files and see what
changes occur in the behavior of virtual populations!

## Repository layout

- `code/` — the NetLogo model (`B3GET.nlogo`) and its extension modules (`extensions/*.nls`)
- `data/` — starting genotype and population files
- `docs/` — the B3GET ODD protocol
- `results/` — example model output

## Citation

Crouse, K. N., Miller, C. M., & Wilson, M. L. (2019). New approaches to modeling primate
socioecology: Does small female group size BEGET loyal males? *Journal of Human Evolution*, 137,
102671.

This model is built on the foundations of several models which can be found under B3GET Classic.
